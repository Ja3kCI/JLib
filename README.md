# JLIB [PAPER] (https://github.com/Ja3kCI/JLib/wiki)

**This api is currently in development phase, you have been warned, any suggestions please leave in issues**

JLib is a Minecraft Library that allows you to simplify your code with a simple and easy to use api, that should make your code not only easy to read but easy to edit and do changes.

Currently the library can do ( with the plan to expand and explore newer additions within the PaperAPI
- [x] Commands 

With current additions including

- [x] Custom inventory api

## Why use this library

The basic language of papermc java is just alot to handle, you have to focus on mutiple files for one thing, like gui making and commands, this library plans to fix it by implementing a smoother way to handle code.

JLib is simply meant to simplify your code.

## Limitations
Currently the api is only available to versions [1.21.4] and above as the api is built on that version, any verion below will likely not function, this library also calls for java 21 and above.
